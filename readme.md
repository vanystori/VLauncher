Thanks for downloading **VLauncher!** 



**VLauncher** is a community, **VanyStudio** project edition of steam, for communities and **VanyStudio** to upload, and showcase their game designs and code. Apply for developer or staff at discord.gg/tBDCGmfea developer rank can upload to the store. At the discord server you can report bugs, give suggestions and get support, as well as socialise!



**HOW TO INSTALL?**

To install VLauncher, download the setup.exe file on the GitHub releases page and set a file location. VLauncher will download its settings to that location. When installation is complete, you will have the option to launch VLauncher, and it will pin to your home screen.
